# Results handoff

Team members submit their real trained results privately to the coordinator using the *existing ZIP templates* under:
- `submissions/baseline/`
- `submissions/fuzzy_rough/`
- `submissions/gbfrs/`

Do not commit public copies of prediction CSVs or derived data until the publication/license question is resolved. GitHub holds the **runnable source code** and safe documentation. The coordinator inserts submission outputs into the offline package to run `tools/compare_results.py`.

No example files in this repository are actual model results.
